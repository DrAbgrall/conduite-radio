Installation et mode hors ligne
Attendez le message « Application prête hors ligne » après la première ouverture avec une connexion.
Après installation, ouvrez Conduite Radio depuis son icône. Si vous utilisez le navigateur intégré d’une autre application, ouvrez d’abord cette page dans Safari, Chrome ou Edge.
Les conducteurs restent dans ce navigateur et à cette adresse. Exportez un JSON pour passer sur un autre appareil. Une première ouverture et l’installation nécessitent un accès au site.
Si vous aviez déjà des conducteurs dans un autre navigateur, exportez-les en JSON puis importez-les dans l’application installée.
